Current state: enemies drop intuitive minecraft loot (undeads drop rotten flesh/bone, storm atronach drops redstone, wolves drop leather, etc) with the possibility of enchanted items being dropped by higher level enemies.
best paired with a mod that lets the player level up by sleeping (because we cannot get into the skyrim tab menu)

v1.0.1 fixes: meat drops buffed and made more immersive, enchanted book drops fixed, enchanted weapon/armor drop chances increased.

v1.0.2 improvement: items now drop like in minecraft, rather than being placed directly into the inventory.

v1.0.3 additions: added armor sets for each of the daedric princes, and the 9 divine (named vanilla armor with various effects)


# SkyCraft Drops – Loot Reference

Alphabetical list of Minecraft items and which Skyrim enemies drop them.

---

### Arrow
- Bandits / Guards / Soldiers / Warriors (1–4, 18%)
- Most humanoids (1–4, 18%)

### Beef (named)
- Bear → “Bear Meat” (18–26, ~92%)
- Cow → “Cow Meat” (14–20, ~92%)
- Deer / Elk / Horse → matching name (12–18, ~92%)
- Dragon → “Dragon Meat” (256, 100%)
- Giant → “Giant Meat” (24–40, ~92%)
- Horker → “Horker Meat” (16–24, ~92%)
- Mammoth → “Mammoth Meat” (128, 100%)
- Wolf / Dog / Sabre Cat / Fox → matching name (8–12, ~92%)

### Blaze Powder
- Flame Atronach (2–4, 75%)

### Blaze Rod
- Flame Atronach (1–2, 25%)

### Blue Ice
- Frost Atronach (1–5, 10%)

### Bone
- Draugr / Vampire / Lich / fleshy undead (1–2, 70%)
- Dragon (12–24, 100%)
- Falmer (1–2, 35%)
- Ghosts / Wisps (1–2, 70%)
- Skeletons (1–2, 70%)

### Book
- Mages (4–6, 70%)

### Bow
- Skeletons (1, 28% — 50% chance to be enchanted)

### Chicken (named)
- Chickens / Hawks / Birds → matching name (4–7, ~92%)

### Crossbow
- Skeletons (1, 8% — 50% chance to be enchanted)

### Diamond
- Dragons (1–2, 40%)
- Ebony-gear enemies (1–2, 40%)

### Diamond Armor / Weapons
- Ebony-gear enemies (1 piece, 14% — 50% chance enchanted)

### Dragon Head

### Egg

### Elytra
- Dragons (1, 2%)

### Enchanted Book

### Ender Pearl
- Mages (1, 4–12% depending on strength)

### Feather
- Chickens / Hawks / Birds (2–5, 75%)
- Hagravens (2–5, 70%)
- Humans (5–8, 4%)

### Glowstone / Glowstone Dust
- Atronachs (1–4 Glowstone, 5%)

### Gold Ingot / Nugget

### Golden Armor / Weapons (with Unbreaking)

DAEDRIC/AEDRIC/TALOS armor sets:

killing certain enemies has a 2% chance to get you some exceptionally powerful armor (little gifts from the daedra and 9 divine for killing the right things in their name)
i won't spoil them all, but as an example, The Hircine set has a 2% chance to drop from any animal.

Each set comes with a passive effect that is always on, and either an on kill effect (kill enemy to get effect) or an on hit effect (take a hit, something happens)
